## Additional coverage detail

- Home profiles: baseline creation/reuse, configured platform, held lock, missing/empty/corrupt stored values, shared credential scopes and native subclient namespaces, TTL renewal.
- Home IDs: reuse across clients, key isolation, UUID creation, NX/TTL commands, existing nonempty opaque session preservation, blank session and invalid user refusal.
- Home replay: reservation, append, stale writer refusal, multiple turns, semantic dedup, stale delete, tombstone and resurrection refusal, corruption/legacy invalid state, CAS PX and expiry.
- Rates: fixed-clock request/input/output per-minute hints, fractional/date retry, absent/zero/invalid/duplicate/oversized retry, malformed/wrong/negated/duplicate error bodies, 5h/7d longest shared windows, model override and fast/direct policy, overage-only behavior.
- Replay pipeline: six-turn local transcript restores thinking+tools, keeps history through local validation failure, clears only on upstream rejection, accounts usage and captures actual request bytes.
- Tool search: native/fallback crossed with buffered/streaming responses, call identity, JSON arguments, token usage, completion, declaration/reference preservation/removal, ordinary prompt/tools retained. Stripping is idempotent and retains untouched large numeric spans.
- Signing: published algorithm vectors, placeholder replacement, covered-byte changes, idempotence, absent-signature no-op, untouched raw number span. This does not establish provider acceptance of the signature.

No Go output fixture is included by an active Claude test. Removed go_unit/go_exec runners, all five broad pipeline replay entrypoints, unused output fixtures and Claude recorder tooling. Removed origin relocation, random-output masks, old-version beta/profile adapters, version supersession rules, recorder-health and ignored-case inventory. Recorded-case family mapping is in /tmp/cliproxy-parity-migration/claude-cases.md. The recorder never proved startup HTTP cancellation; the new stream-drop contract does not claim it does.

Login persistence now asserts semantic retained settings instead of sorted JSON keys, HTML escape choices or a trailing newline. Saved filename identity stays explicit because operators reuse credential files. No Go or Rust output fixture was regenerated or relabelled.
