# Common test migration

Owned crate: `crates/cliproxy-internal`. Runtime behavior is unchanged. The only non-test source changes remove replay-only test instrumentation and update module documentation. Native Codex request behavior remains governed by `docs/codex/CONTRACT.md`.

All 35 Rust entry points in the inventory are accounted for below: 31 migration/removal entries and 4 keep entries. Test-only Go recorder adapters, lookup overrides, exact fixture population requirements, error-prose normalization, and output exception tables are removed. The broad matrices now test explicit accepted operations, not another implementation's parser quirks. They do not claim exhaustive compatibility with every historical gjson/sjson API.

## Removed fixture dependencies

No Rust source under cpa-common includes any Go expectation fixture. Only `codex_context_window_error_live.json` remains included; its independent live provenance and tests are unchanged.

Unused fixtures eligible for parent cleanup: `codex_catalog_go.json.gz`, `codex_client_go.json`, `gemini_schema.json.gz`, `go_calls.jsonl.gz`, `go_signature_matrix.jsonl.gz`, `go_thinking_matrix.jsonl.gz`, `json.json`, `payload_go.json`, `query_go.json`, `sjson_go.json`, `sjson_go_vectors.json`.

The five inventoried recorder entry points (`TestRSFixCodexCatalog`, `TestRSFixCodexClient`, `TestRecordThinkingMatrix`, `TestRecordSignatureMatrix`, `TestRSFixKimiVectors`) are obsolete after their consumers are migrated. Parent owns recorder removal across the repository. `tests/reference/unicode` is separate provenance for production Unicode compatibility tables and should not be deleted without checking those dependencies.
